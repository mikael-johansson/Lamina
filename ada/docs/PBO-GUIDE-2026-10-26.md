# PBO on ada: step by step (ASUS ROG Crosshair VIII Extreme, BIOS 2002, Ryzen 7 5700X)

Why: the CPU expert pool is power-bound.  Under the expert kernels' instructions on all 8 cores the CPU sits at its
76 W package power limit (PPT) and runs ~4.0 GHz; one core alone runs 4.65 GHz.  Measured 2026-10-26 with
`ada/bench/cpu/cpu_power.sh`: idle 17 W; 8 cores AVX2 77 W at 3975-4000 MHz; 1 core AVX2 47 W at 4650 MHz;
Tctl at most 65 C.  Raising the limit should lift all-core clocks toward ~4.4-4.5 GHz: an estimated ~+10-12% CPU pool
throughput, ~+5-8% total at C=2-4, ~+0.5-1% at C=1.  Idle power does not change (PBO only raises ceilings).

Time needed: ~10 minutes in the BIOS, then ~30 minutes of checks.

## 0. Before you reboot

1. Nothing is running on the GPUs or the CPU pool (no Strata server, no benchmark).  `vllm-qwen.service` restarts by
   itself after the reboot.
2. Note the current settings you care about, in case a reset is needed: memory profile (D.O.C.P. / XMP, DDR4-3200),
   PCIe slot bifurcation / lane settings for the two 3090s (x8/x8), fan curves, anything else changed by hand.

## 1. Enter the BIOS and save the current setup as a profile

1. Reboot, press **Del** (or F2) during POST.
2. If the EZ Mode screen shows, press **F7** for Advanced Mode.
3. Go to **Tool -> ASUS User Profile**.  Save the current settings to an empty slot, name it e.g. `stock-2026-10`.
   This is the way back: loading it restores everything, including D.O.C.P. and the PCIe settings, unlike F5 (load
   optimized defaults), which resets those too.

## 2. Set PBO (Extreme Tweaker menu only)

ASUS exposes PBO in two places: **Extreme Tweaker -> Precision Boost Overdrive** and
**Advanced -> AMD Overclocking**.  Use only the Extreme Tweaker one and leave the other on Auto / Disabled: the two can
override each other.

1. **Extreme Tweaker -> Performance Enhancer**: leave at **Default / Auto** (it is ASUS's own preset PBO; do not
   combine it with manual limits).
2. **Extreme Tweaker -> Core Performance Boost**: **Auto / Enabled** (it should be already).
3. **Extreme Tweaker -> Precision Boost Overdrive**:
   - **Precision Boost Overdrive**: `Manual` (on some BIOS versions `Advanced` first, then **PBO Limits: Manual**).
   - **PPT Limit [W]**: `120`
   - **TDC Limit [A]**: `80`
   - **EDC Limit [A]**: `120`
   - **Precision Boost Overdrive Scalar**: `Auto` (or `1X`).
   - **Max CPU Boost Clock Override**: `0` / `Disabled` for now (it only raises single-core peaks).
   - **Platform Thermal Throttle Limit**: `Auto` (90 C for this CPU).
4. **Curve Optimizer** (same submenu, or Extreme Tweaker -> Precision Boost Overdrive -> Curve Optimizer):
   - **Curve Optimizer**: `All Cores`
   - **All Core Curve Optimizer Sign**: `Negative`
   - **All Core Curve Optimizer Magnitude**: `10`
   This lowers the voltage at each clock, so the same watts buy more MHz.  It is the part that can be unstable; start
   at 10, not more.
5. Leave everything else (CPU core ratio, voltages, LLC) on **Auto**: no fixed all-core overclock.
6. **F10** -> save and reset.

## 3. After boot: check it took

From `~/git/strata` (the tools are in `ada/bench/cpu/`; the workspace copies are in `bench/`):

```
sudo sh bench/cpu_power.sh
```

Expect: idle still ~17 W; **8 cores AVX2 above 77 W** (up to ~120 W) **and above ~4000 MHz** (hopefully 4400+);
1 core AVX2 still ~4650 MHz.  If 8 cores are still at ~77 W / ~4000 MHz, the PBO limits did not apply: go back to
the BIOS and check that the Advanced -> AMD Overclocking copy is not set and overriding them.

Temperature under the all-core load (`sensors | grep Tctl` while it runs): fine up to the mid 80s C.  If it reaches
90 C, the CPU throttles itself (safe, but the limits are then more than the cooler can carry: lower PPT to 105 W).

## 4. Stability

Curve Optimizer instability usually shows at **light or idle load** (a reboot, a freeze, a single-core error), not
under the full load.  So test both:

1. Full load, 10 minutes: `for i in 0 1 2 3 4 5 6 7; do taskset -c $i bench/avxburn 600 & done; wait`
   (or `stress-ng --cpu 8 --cpu-method matrixprod -t 10m` if installed).
2. A real Strata run: a long benchmark (the corpus through the server) and some normal use for a day.
3. Machine-check errors after each: `journalctl -k -b | grep -iE "mce|machine check|hardware error"`
   (no output is good).

If anything fails: back to the BIOS, Curve Optimizer magnitude `5` (or `0`), and re-test.  If it still fails with
the curve at 0, lower PPT/TDC/EDC (e.g. 105 / 75 / 110).

If stable for a few days at -10, -15 can be tried the same way (more MHz per watt), with the same tests.

## 5. Measure the effect (Claude does this)

1. `bench/cpu_power.sh` (power, clocks), `bench/kbench` (the CPU expert kernels' throughput at 1-8 threads).
2. C=1 and C=2 server benchmarks against the baseline from 2026-10-26 (`ada/bench/results/c4-r*` for the split
   config at C=1: 224.5-225.3 tok/s geometric mean).

## Going back

BIOS -> **Tool -> ASUS User Profile -> load `stock-2026-10`** -> F10.  Or just set Precision Boost Overdrive back to
`Auto` / `Disabled` and Curve Optimizer to `Disabled`.

If the machine does not POST after a change: power off, wait, power on; the board falls back to safe settings after
a few failed boots.  The Crosshair VIII Extreme also has a **Retry / Safe Boot button** on the board and BIOS
Flashback; clearing CMOS (the **Clear CMOS** button on the rear I/O) resets everything to defaults (then load the
saved profile).
